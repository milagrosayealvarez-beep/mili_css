# Proyecto Final - Desarrollo Web

Sitio web personal desarrollado como proyecto final del curso de Desarrollo Web en Coderhouse.

## 🚀 Sitio desplegado
Podés ver el proyecto online acá: [milagros-alvarez.netlify.app](https://milagros-alvarez.netlify.app)


## 🛠️ Tecnologías utilizadas
- HTML5 semántico
- SCSS / SASS (Variables, Mixins, Nesting, Partials)
- Bootstrap 5
- Librerías de animación (AOS / Animate.css)

## 📁 Estructura del proyecto
- `/pages`: Archivos HTML secundarios.
- `/scss`: Archivos de estilos Sass y partials.
- `/styles`: CSS compilado.
- `/assets`: Imágenes y recursos multimedia.
